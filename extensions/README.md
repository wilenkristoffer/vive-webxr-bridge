# Extensions

Every folder in here that contains a `manifest.json` is loaded into the launcher's Edge window on start.

## YouTube 360° / VR180 videos

YouTube no longer shows a VR button on desktop. To watch 360° and VR180 videos in the headset, download
[video2webxr](https://github.com/phit/video2webxr) (ISC licence, by phit) from its
[releases page](https://github.com/phit/video2webxr/releases) and unzip it into `extensions/video2webxr/`,
so that `extensions/video2webxr/manifest.json` exists. It adds a cardboard icon to YouTube's video player.

Extensions you put here are not part of this repository and are ignored by git.
